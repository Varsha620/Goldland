# Goldland Staff Testing — Version 0.1

This release is for reviewing screens and workflows only. It is not the live shop system.

## Open the application

1. Open the testing link in Chrome or Edge.
2. Enter the testing password: `goldland2026`.
3. Use only made-up customers, phone numbers, bills and amounts.
4. Start with the **Test guide** button at the bottom-right.

## Report feedback

Open the screen where the problem occurs and select **Report feedback**. Describe what happened and what should happen instead. Select **Save & share**, then send the prepared message to the project owner through the phone's share menu or by pasting it into WhatsApp.

Use these results consistently:

- **Cannot complete:** a necessary workflow is blocked.
- **Works but needs changes:** the workflow can finish, but something is wrong or confusing.
- **Works correctly:** the workflow matches actual shop work.
- **Not used by our shop:** the feature is unnecessary for this shop.

## Important limitations

- Test data stays in the browser used to enter it.
- Different devices do not share transactions.
- Clearing browser data removes test transactions and saved feedback.
- Do not use this release for real billing, accounting or customer information.
- The version shown at the top of the app must be included with all feedback.

## First testing assignment

Test **Masters** and **Sales** first. Do not attempt every module at once. After these two modules are reviewed and corrected, proceed to Purchase and Stock.
